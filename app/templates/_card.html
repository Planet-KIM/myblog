{# _card.html: post card macro shared by the portal lists (blog home, tag feed, search). Macro: post_card(post, show_author=true) renders one Bootstrap grid column with a whole-card link, optional thumbnail, optional author row (avatar ringed in the author's accent color), category/private badges, title, preview and meta (date, views, reading time). post: BoardPost with the list extras the routes attach (thumbnail, preview/preview_html, view_count, reading_minutes, user, category). show_author: render the author row (false on the author's own blog home). Assets: static/css/post_card.css (link it from every page that imports this macro); image fallbacks via data-img-fallback (image-fallback.js, base.html). #} {# 포털 리스트(블로그 홈·태그 피드·검색) 공용 포스트 카드. 여러 페이지에서 루프로 호출되므로
