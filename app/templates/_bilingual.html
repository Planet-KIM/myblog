{# _bilingual.html: macros for bilingual posts ({{한국어||English}} in the body). bilingual_title(ko, en): the post title; with an English title it renders the same .bi-pair markup static/js/bilingual.js makes in the body, so the language switch changes the title too. one_language(ko, en): text that has a Korean and an English version but shows only one (.bi-one > .bi-ko + .bi-en): the chosen language, and Korean under 함께. It is not a .bi-pair, so it never turns the language switch on by itself. reading_time(minutes, minutes_en): the header's "N분 읽기", one_language when there is an English estimate. Used by board_detail_writer.html, board_detail_magazine.html and _post_card.html; pages link static/css/bilingual.css and static/js/bilingual.js. #} {% macro bilingual_title(ko, en) -%} {% if en %}{{ ko }}{{ en }}{% else %}{{ ko }}{% endif %} {%- endmacro %} {% macro one_language(ko, en) -%} {% if en %}{{ ko }}{{ en }}{% else %}{{ ko }}{% endif %} {%- endmacro %} {% macro reading_time(minutes, minutes_en) -%} {{ one_language(minutes ~ '분 읽기', minutes_en ~ '분 읽기' if minutes_en else none) }} {%- endmacro %}
